# Zyad Chat — WhatsApp-style chat app (standalone)

A from-scratch WhatsApp-like chat app: its own code, its own server, its own
database. Anyone who opens the app creates an account and can message other
people inside the app. It does **not** connect to WhatsApp and cannot receive
messages from WhatsApp.

## What it has

- Username + password accounts (no phone number / SMS signup)
- Profiles with photo and about text
- 1-to-1 chats (DMs) and group chats (create group, add members)
- Text messages, photo / video uploads, voice notes recorded in the browser
- Sent / delivered / read ticks (✓, ✓✓, blue ✓✓)
- Online / last-seen presence and typing indicator
- Reply to a message, delete for me / delete for everyone, emoji reactions
- Unread counts, chat search, message search inside a chat
- WhatsApp-style look (green theme, chat list + chat window, message bubbles)
- Works in a phone browser and on desktop

## What it does NOT have

- No connection to WhatsApp (messages from WhatsApp cannot arrive here)
- No end-to-end encryption — messages are stored on the server
- No voice / video calls (version 1)
- Photos, videos and voice notes are stored in Postgres, so they survive a
  free-hosting restart (nothing is kept only on disk)

## Tech

Node.js + Express, PostgreSQL (`pg` driver, `DATABASE_URL` env var).
The frontend is plain HTML/CSS/JS served as static files by the same server —
no build step. Session tokens are stored in the database, so logins survive
a server restart.

## Deploy to Render (free) — exact steps

1. **Push this folder to GitHub**
   ```bash
   cd chat-app-deploy
   git init
   git add .
   git commit -m "Zyad Chat App"
   git remote add origin https://github.com/<your-username>/zyad-chat-app.git
   git push -u origin main
   ```

2. **Create a free Postgres database (Neon)**
   - Go to https://neon.tech and create a free account + project.
   - Copy the connection string (it looks like
     `postgresql://user:password@ep-xxx.neon.tech/neondb?sslmode=require`).
   - Neon free tier does not expire. Do **not** use Render's free Postgres —
     it is deleted after 30 days.

3. **Create the web service in Render**
   - Go to https://render.com → **New → Web Service** → pick the GitHub repo.
   - Render reads `render.yaml` from the repo automatically.
   - Plan: **Free**.

4. **Set the environment variable**
   - In the Render service → **Environment** → add:
     - `DATABASE_URL` = the Neon connection string from step 2
   - `SESSION_SECRET` is generated by Render from `render.yaml`.
   - `NODE_ENV` is set to `production` by `render.yaml`.

5. **Deploy and open it**
   - Click **Deploy**. When it says Live, open the URL Render gives you
     (like `https://zyad-chat-app.onrender.com`).
   - Free services sleep after 15 minutes with no traffic; the first visit
     after that takes about a minute to wake up.
   - Share that link with your friends — only people with the link can open
     it, and everyone still needs an account (username + password) to chat.

## Run locally

```bash
npm install
cp .env.example .env        # edit DATABASE_URL to point at your Postgres
npm start                   # listens on http://localhost:3000
```

Local Postgres (Ubuntu):
```bash
sudo apt-get install -y postgresql
sudo -u postgres psql -c "CREATE USER chatapp WITH PASSWORD 'chatapp';"
sudo -u postgres psql -c "CREATE DATABASE chatapp OWNER chatapp;"
```

## Notes

- The app starts with an **empty database** — no demo or seed accounts.
- First user to sign up just creates a normal account like everyone else.
- Keep `SESSION_SECRET` private; never commit a real `.env` file.
